`main.py` writes one line — a software patch note for a bug in human biology, 160 characters max — to `/output/entry.txt`:

> v3.2.1: fixed a bug where the brain replayed your most embarrassing moment from 2009 every night at 3 a.m.

Run it with `python3 main.py` (Python standard library only, no dependencies).
